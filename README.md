Entomophagy Newsletters

Curated archive of PDF newsletters downloaded from https://www.entomophagy.or.jp/newsletter.

Conventions
- Keep tracked PDFs at the repository root (do not reorganize into subdirectories).
- Newsletter filenames: `Vol.%02d_<title>.pdf` for series; other documents should use the visible document title.
- Use `renamePdfs.swift` to normalize or fix PDF filenames: `./renamePdfs.swift path/to/file.pdf`.

Workflow
- Treat this repo as a curated archive. Add, remove, or rename PDFs deliberately.
- Do not commit temporary working files to the repository root.

See `renamePdfs.swift` for renaming logic and rules.
